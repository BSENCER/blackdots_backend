# BlackDots - Odoo Partner Website

Azərbaycan dilində hazırlanmış professional Odoo partner website.

## 📁 Fayl Strukturu

```
blackdots-website/
│
├── index.html          # Ana səhifə
├── services.html       # Xidmətlər səhifəsi
├── apps.html          # Odoo Apps səhifəsi
├── about.html         # Haqqımızda səhifəsi
├── contact.html       # Əlaqə səhifəsi
├── style.css          # Əsas CSS faylı
└── README.md          # Bu fayl
```

## 🎨 Dizayn Xüsusiyyətləri

- **Rəng Sxemi:** Ağ, Qara və Odoo Purple (#714B67)
- **Fontlar:** 
  - Playfair Display (Başlıqlar)
  - Work Sans (Mətn)
- **Responsive:** Mobil, tablet və desktop uyğun
- **Animasiyalar:** Smooth transitions və hover effektləri

## 🚀 İstifadə

1. Bütün faylları bir qovluğa yükləyin
2. `index.html` faylını brauzerdə açın
3. Naviqasiya menyu vasitəsilə səhifələr arasında keçid edin

## ✏️ Fərdiləşdirmə

### Məlumatları dəyişmək:

1. **Şirkət adı:** HTML fayllarında "BlackDots" sözünü axtarıb dəyişdirin
2. **Əlaqə məlumatları:** `contact.html` faylında email, telefon və ünvan dəyişdirin
3. **Rənglər:** `style.css` faylında `:root` dəyişənlərini dəyişdirin
4. **Komanda:** `about.html` faylında team-member bölməsini redaktə edin

### Rəng dəyişikliyi:

```css
:root {
    --color-black: #0a0a0a;
    --color-white: #fefefe;
    --color-purple: #714B67;  /* Bu rəngi dəyişdirin */
}
```
